# Empty printable tile board

This directory owns the printable board tray that receives 64 separately printed
electronic tiles. The board itself is deliberately empty: it has no permanent
checkerboard squares, modular tile meshes, or raised guide rails.

A continuous flat floor accepts the mating adhesive-backed Velcro pads. The
perimeter frame establishes the 320 mm playing area without internal guidelines.
Two blind pilot holes per tile position align with the optional reinforced screw
holes in each tile tray. The pilots do not break through the board underside.

The complete 340 mm tray fits the large-format reference printer after the
reserved bed margin. Tile projects remain small enough for the compact reference
printer.

Run `make regen-all` from the repository root to regenerate
`board-skeleton.blend` and the empty-board inspection render.
